## TOJ - Touch The Object - a Gaming App for iOS<br>

Student: Oliver Hartmann

TOJ - Touch the object is a game about reaction. The aim is to touch on a random position displayed object within a specific time frame. A person earns one point per touched coin. If a person touches the diamond object it gets 10 points. The diamond object will be displayed with a chance of 10%. The game ends after missing three object or after one minute.

The app has been developed using the folling coding languages and frameworks:

- Swift
- SwiftUI
- SwiftData
- Foundation
- AudioToobox
